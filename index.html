How To Update Weekly

1. Son updates the Excel file like always

2. Open the GitHub repo in Safari (desktop view)

3. Tap the existing stats.xlsx → trash icon → commit

4. Add file → Upload → drag in the new stats.xlsx → commit

Everyone's app refreshes with the new data the next time they open it (or hit Refresh above).

Player Bios & Photos

Bios: Add a new sheet to your Excel called Players with these column headers in row 1:

Player, Height, Wingspan, Age, Position, Jersey #, Years Playing, Hometown, Nickname, Favorite Player, Signature Move, Bio

One row per player. Fill in what you want, leave the rest blank. The Player name must match exactly what's in the Log sheet (Hudson, Joe, Jake, etc).

Photos: In your GitHub repo, create a folder called photos. Upload one image per player named like willy.jpg, matt.jpg (lowercase first name only).

If a player doesn't have a photo, their initial shows in orange as a placeholder.
